# 🐵 跳跳猴

点一下就接入。网页、视频和游戏走自己的通讯协议，外面套着 HTTP/3 加密。出口可以只用 Cloudflare Worker，也可以再加一台落地。

⬇️ Windows 安装包：<https://github.com/tiaotiaohou559/tiaotiaohou/releases/download/windows/tiaotiaohou-Setup.exe>

## 🔐 自研通讯协议

协议名叫 **RSQ/1**。它规定一条本地连接怎么变成一条加密请求，不借用别人的代理帧。

一条连接对应一条请求。请求里带着协议版本、目标网址和端口，正文是原始字节，回来的正文也是原始字节。中间不再拆成多路小包，所以免费档那点 CPU 几乎只花在接通和结束上。

加密套在这条协议外面，分三档，客户端自己换：

| | 通道 | 什么时候用 |
| --- | --- | --- |
| 🚀 | **HTTP/3** | 默认。跑在 QUIC 上，加密是 TLS 1.3，端口 UDP 443。握手短，丢几个包也不用整段重来。 |
| 🔁 | **HTTP/2** | UDP 被挡住，或者这条路变慢。加密仍是 TLS。看视频、拉流时如果它更稳，会单独改走这条。 |
| 🛟 | **HTTP/1** | 前两条都不通时的保底。 |

令牌只用来确认这是你的节点。网页优先留在 HTTP/3，不用手动切换。

## 🛣️ 三种出口

同一个客户端，节点可以选不同的走法。

| | 走法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| ☁️ | **Cloudflare Worker** | 不用自己的服务器。出口在 Cloudflare，走免费额度。普通网页能开。 | 有的网站认 Cloudflare 的地址，会进不去。游戏 UDP 过不去。每天大约 10 万次请求，开一条新连接算 1 次。 |
| 🟠 | **Cloudflare + 落地** | 域名挂橙云，流量回源到落地服务器。不计 Worker 次数，优先 HTTP/3。网页、橙云网站、游戏 UDP 都能走。 | 要有一台落地。网站从这台机器的地址出去。 |
| 🧩 | **Cloudflare Worker + 落地** | 先进入 Worker，再从落地访问网站。入口藏在 Cloudflare 后面，出口是自己的地址。填了落地地址时，游戏走 UDP。 | 多一跳。Worker 的免费次数照样算，落地也要自己准备。 |

首页节点下面的三个标记，对应这三种能开什么：网页、橙云网站、游戏 UDP。

## 🎯 Cloudflare 优选 IP

本机设置里可以打开。它不改你的节点域名，只是在 Cloudflare 的很多地址里挑一条现在更快的，连的时候钉在这条上。

晚上同一条地址背后的路可能变堵。本机里点 **换一个**，会跳过当前地址，再挑一条能打开这个节点的。只对经过 Cloudflare 的节点生效，纯直连落地不会用它。

## 💸 免费额度

Worker 和 Worker + 落地走 Cloudflare 免费档，不用按流量买出口。

大约每天 10 万次请求。首页能看到今天用了多少。橙云 + 落地不走 Worker，不占这个次数。内网、本机和 25 端口不会放行。

## ✨ 特别的功能

连上以后自己会选路，不用在上网、看视频、打游戏之间来回点。

- 🚀 **多路一起准备**：HTTP/3 和 HTTP/2 同时连着，谁先通就用谁。网页留在更快的那条。
- 🎬 **视频单独选**：看视频、拉流时如果 HTTP/2 更稳，只把这一类改过去，别的流量不动。
- 🎮 **游戏 UDP**：有落地时，游戏单独送到落地的 8444，不跟网页抢同一条路。
- 🇨🇳 **国内直连**：百度、淘宝不绕出去。内网地址也不进代理。
- 📶 **首页测速**：正在用的这条连接，能看延迟、下载和上传，测的时候数字会跟着走。
- 🏳️ **节点看国籍**：名字里能认出的国家，列表和首页都会挂上国旗。
- ✅ **节点只测通不通**：点测试看这条能不能用，不拿延迟来排名。

节点可以有很多条，点一条就换过去。

- 📥 **导入和订阅**：贴一条或一批配置，也可以填订阅地址。订阅失败会自己再试，手动加的节点不会被冲掉。
- 🎁 **分享能收口**：可以设过期时间和能用几次。停用之后，这台电脑再导入那串配置会拒绝。
- 🔀 **掉线换下一条**：当前节点不行时，自动去试列表里的下一条。
- 🚧 **断了先拦住**：掉线时先停住，不把流量漏回真实网络。你自己断开或退出，仍会关掉代理。

本机这一页是开关，改完就按这个用。

- 🎯 **优选 IP**：见上面。还能重新扫描，或换一个地址。
- 🌐 **打开打不开的网站**：只用 Worker、没有落地时，有的站进不去。打开这个之后再开一次浏览器。
- 🖥️ **系统代理**：连上后浏览器跟着走。代理只听 `127.0.0.1`，浏览器走 `8080`，SOCKS 走 `1080`。关掉软件会清掉。
- 🔌 **开机和换网**：可以开机静默连上。网络变了会重新接，锁屏不会自己断。
- 📊 **今日额度**：首页能看到免费档用了多少，快用完会提醒。
- 🩺 **诊断**：检查节点、本机代理和当前出口，结果可以复制。
- 🔤 **中英文**：右上角切换，不用整页重开。
